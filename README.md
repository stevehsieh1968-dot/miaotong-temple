# 妙通寺・線上禮佛

在廟埕走動、入寺禮佛：點香、拜拜、點天燈（佛光照著天燈飛向彩虹）、靜坐（心經由佛口加持）、點光明燈、長生祿位、祖先牌位、捐款護持。支援手機。

- `index.html`：網站主程式
- `gate2.jpg`：廟埕場景
- `hall2.jpg`：大雄寶殿場景
- `sky.png`：天空遮罩（彩虹只出現在天空）
- `vercel.json`：Vercel 設定

## 部署
在 Vercel 匯入此 repo，Framework Preset 選 **Other**，不需要 build 指令，直接 Deploy。

## 說明
- 光明燈、祿位、牌位、捐款登記只存在訪客自己的瀏覽器；捐款未接金流。
- 「此刻人數／看到其他香客」只在 Claude 版連結上運作，獨立部署時只會看到自己。
